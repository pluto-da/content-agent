# 常见问题
- Agent 会自己发布吗？不会。发布、评论、私信永远由大哥本人点击。
- 进化是不是在改模型？不是。进化指经验记录、技能版本和经确认的设定修订，模型权重不变。
- 没接生图模型怎么办？文字照常完成，配图等接上再出；对话里会出“去配置”按钮。
- 花钱什么时候问？默认单次预计 ≥¥1 或当天累计 ≥¥10 先问，视频每次都问；可在“我的 → 设置”改。
