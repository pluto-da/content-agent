# 各角色怎么接
- 模型按“能做什么”分 11 类：文本、推理、快速、看图、生图、改图、配音、转写、视频、向量、重排。
- 入口：我的 → 模型 → 选一类 → 添加服务商（或用已有账号）→ 填模型名 → 测试。
- 一家服务商的 Key 默认在它的所有能力间共用；每一类也可以单独填地址和 Key。
- 模型名就是请求里的 model 参数，以服务商文档或“获取列表”为准；App 不写死任何模型名。
- Key 只存在本机加密存储里，界面只显示末四位，不进导出、日志、截图。
