# AI 标识与版权须知
依据《人工智能生成合成内容标识办法》（国家网信办等四部门，2025-09-01 施行）与强制性国家标准《网络安全技术 人工智能生成合成内容标识方法》。
1. 显式标识：生成图片默认在角落加“AI 生成”小标（可在设置关闭，关闭时提醒发布时仍需在平台勾选声明）；音频在卡片与文件名中标注；视频卡片标注。
2. 隐式标识：保存的 PNG 写入 tEXt（AIGC、模型、服务提供者、内容编号、时间）；其他格式能写则写，不能写的在 assets/index.jsonl 记录。不剥离服务商已有标识。
3. 发布检查：含 AI 媒体 → 提醒在平台勾选 AI 生成声明；含真实人物或品牌 → 提醒授权；复刻音色 → 必须已确认授权；引用他人文字 → 提醒注明出处。
4. 改图只对自有或已授权的图片；声音复刻、人脸能力默认不开放，调用前强制授权确认。
