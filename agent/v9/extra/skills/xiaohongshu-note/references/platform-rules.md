# 小红书平台规范（按需读取）
- 标题 ≤20 字；正文建议 300–800 字；话题标签 3–8 个。
- 配图 3–9 张，竖版 3:4 最常见；首图即封面，决定点击。
- 含 AI 生成图片时，在发布页勾选 AI 生成声明（由大哥本人勾选）。
- 不写诱导关注、点赞、分享的句子；不站外导流。
- 规则以平台当天官方说明为准；本文件只是速查。
