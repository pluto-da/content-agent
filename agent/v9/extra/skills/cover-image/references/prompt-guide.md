# 生图提示词指南
结构：主体 → 场景 → 构图 → 光线 → 风格 → 画幅。
- 主体写具体：“木桌上一碗冒热气的馆陶小米粥”，不写“美食”。
- 画幅：小红书 3:4，抖音 / 视频号 9:16，公众号头图 2.35:1。
- 不生成真实人物的肖像或可识别品牌标志；不仿冒他人作品风格并声称原创。
- 同一组配图保持同一风格，不混用。
