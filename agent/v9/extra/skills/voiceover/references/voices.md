# 音色速查（以服务商当天文档为准）
- 小米 MiMo `mimo-v2.5-tts`：mimo_default、冰糖、茉莉、苏打、白桦等预置音色；风格描述放 user 消息，合成文本放 assistant 消息。
- 百炼 `cosyvoice-v3-flash`：longanyang 等；本机走 HTTP SpeechSynthesizer。
- 复刻音色必须先确认声音授权（发布检查强制）。
