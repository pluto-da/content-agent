# 主动提醒偏好
- 每天最多主动提醒：3 条
- 免打扰时段：22:30–08:00（北京时间）
- 要提醒：到期提醒、待发布草稿（超过 3 天）、视频生成完成、中断任务、该录数据的内容、变现规则需重新核实
- 每周汇总一次：待确认的进化提案与降级提议
- 不提醒：热点更新（大哥自己看）
- 大哥说“少提醒 / 别提醒 X”时，在这里改成一条规则（带日期与原话），一直有效，直到他改。
