## 步骤
1. 读 USER.md 的目标与可接受方式、账号画像的阶段；缺“能接受哪些变现方式”且会影响推荐时，问一个问题。
2. 用 monetization_paths 取官方路径：每条带官方链接、上次核实日期、门槛摘要。超过 30 天未核实 → 先说“这条规则需要重新核实”。
3. 推荐 1–3 条：为什么适合现在的阶段、离门槛还差什么、下一步做什么内容来靠近（只靠真实内容与真实粉丝）。
4. 每条都写“门槛与规则以当天官方页为准”，并给“打开官方页”按钮。
5. 不承诺能赚多少；如大哥问预期收入，只能基于他已有数据给区间并说明不确定性，或说明没有数据无法估计。

## 禁止
推荐非官方渠道、灰产、刷量冲门槛、买卖账号、违规导流到站外交易。
