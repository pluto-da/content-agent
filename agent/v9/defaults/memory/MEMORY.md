# memory/ 记忆详情
用途：长期记忆的详细内容。根目录 MEMORY.md 是精华，这里是全部。
结构：preferences.md（偏好）；accounts/（各平台账号画像）；people/（人物）；topics/（主题）；lessons/（经验：证据 + 结论 + 置信度）；daily/（每日日志）。
格式：Markdown + front matter（id、type、related、updated、source、confidence）；每条一行，行尾写条件与来源。
加载：按需检索（关键词 + 向量）；daily/ 只检索不注入，按 30 天半衰期衰减。
写入规则：该记——稳定偏好（带条件）、确定的画像信息、大哥要求记住的事、重要决定；不记——密钥、一次性数值、原始素材拷贝、临时状态、大哥说不记的。推断的标 inferred 并写依据，用之前先确认。记的范围不比大哥说的更宽。同一主题改写原条目，不留矛盾。
删除：大哥说“忘掉 X”时，检索所有相关条目 → 列出确认 → 删除 → 再检索验证为 0 → 在根 MEMORY.md“不要记住”写规则。
读写权限：Agent 只能提议，大哥确认后写入；大哥可直接编辑删除。
