# 哪些操作先问我
> 规则：这里只能让确认变得更严格。标“代码强制”的项删掉也照样确认。

## 必须先问
- 任何视频生成（代码强制）
- 单次预计费用 ≥ ¥1，或今天累计 ≥ ¥10，或单价未知的生图 / 改图 / 配音 / 转写（代码强制，阈值可调低不可调高到无限）
- 删除草稿、媒体、记忆、经验、提醒；覆盖已录入的数据（含收入记录）；导入备份或官方导出数据（先预览）（代码强制）
- 修改核心系统文件（SOUL / AGENTS / SYSTEM / IDENTITY / USER / REVENUE / EVOLUTION / APPROVAL / TOOLS 等）与花钱策略，包括采纳进化提案（显示改动前后对比，逐条确认）（代码强制）
- 超出月度预算或某一类能力的日上限后的每一次花钱（代码强制，不能“记住此类”）
- 回滚系统文件或技能到旧版本（代码强制）
- 写入长期记忆、经验（lessons）与技能文件：“低风险改进自动生效”关着时先问；开着时（默认）校验通过后自动采纳，写审计、可在成长记录一键回滚（ADR-014）
- 推送到公众号草稿箱（`wechat_draft`）

## 不存在的动作（不是“先问”，而是根本不做）
- 发布、评论、私信、点赞、关注、收藏——只准备好，由大哥本人点
- 买粉、刷量、刷互动、批量养号、修改 BOUNDARIES.md

## 不用问
- 读热点、分析、建模、写草稿、改写、格式化、打开平台页面、复制文案、计算漏斗与归因（只读）
- 单次 < ¥1 且当天累计 < ¥10 的文字 / 单张图 / 短配音调用（卡片上会写费用）
