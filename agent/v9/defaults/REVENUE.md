# 收益目标

## 北极星
- **真实收入（元，按自然月统计）**。类型：平台创作者收益（创作分成、流量主、创作者激励）／广告与商单（星图、蒲公英、互选等官方平台）／带货佣金（橱窗、返佣商品、小店）／知识付费与私域转化（大哥本人在合规渠道成交）／其他。
- 每笔收入记录：日期、平台、类型、金额、口径（已到账 / 平台确认的预估）、关联内容（可多个，也可“未知”）、来源（user_entered 表单 / official_export 文件名与 hash）、备注。
- 收入只来自大哥录入或他导出的官方数据。没有记录时，回答“还没有收入数据”，不估算、不编。

## 漏斗（每层的数字同样只来自录入或官方导出）
曝光（展现 / 播放 / 阅读）→ 互动（赞、评、藏、转）→ 关注（新增关注）→ 转化（商品点击、进店、咨询、加入付费）→ 收入。
复盘时指出最弱的一层，建议优先改那一层。

## 收益假设（每个选题与草稿都挂）
格式：`走 <变现路径>；主要影响 <漏斗层>；看 <指标>；<24 小时 / 72 小时 / 7 天> 后验证；对照：<同类旧内容或另一版本 / 无>`。
例：“走视频号创作分成；主要影响曝光；看播放与完播；72 小时后验证；对照：上周同主题那条。”

## 归因
- direct：平台给了单条内容的收入（如单条视频分成、单篇返佣），直接归到该内容。
- allocated：只有账户级收入时，按同期各内容的转化层占比分摊，标“分摊估计”，不当事实。
- user_tagged：私域、知识付费等，由大哥标注来自哪条内容。
- unattributed：缺少依据时不分摊，标“未归因”。
每条归因带置信度；复盘里分开显示四种归因的金额。

## 复盘排序
按收入排序；还没有收入时，按最接近收入的漏斗层排序并说明。每次复盘给：赚钱最多（或最接近赚钱）的 3 篇、最弱的一层、下一步 1–3 个可验证的动作。

## 变现路径建议
- 按账号阶段与平台给 1–3 条官方路径（见 docs/monetization-guide.md：如抖音创作者激励与巨量星图、小红书蒲公英、视频号创作分成与互选、公众号流量主与返佣商品、知识付费）。
- **各平台官方变现门槛与规则会变，每次展示都附官方链接与上次核实日期，并写“以当天官方页为准”**；超过 30 天未核实的条目先提示重新核实。

## 红线（硬边界同样强制）
- 不承诺收入或涨粉。
- 只用真实流量：不刷量、不买粉、不做虚假互动、不诱导违规、不搬运侵权、不绕风控、不自动发布。
- 收入与数据不编造。
