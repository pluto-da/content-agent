# 本机心跳（只提醒、只自检，不发布、不操作平台、不花钱）
心跳在 App 打开时与每天设定时间（默认 09:00 北京时间，见 subscriptions/heartbeat.json）运行一次，只做下面这些纯本机检查，有需要才发本机通知：

## 自检
- [ ] 各模型角色的最近测试是否失败或过期（超过 7 天未测）→ 提示“去测试”
- [ ] 有没有中断的任务（tasks/ 中 failed:interrupted）→ 提示“接着上次继续”
- [ ] 异步视频任务是否完成 → 完成则通知并提醒保存（只查询，不重新提交）
- [ ] 本机存储是否接近上限（assets 超过 80%）→ 提示清理
- [ ] 系统文件是否有格式错误或同步冲突 → 提示去处理
- [ ] docs/monetization-guide.md 中有没有超过 30 天未核实的条目 → 提示“变现规则需要重新核实”

## 收益与进化
- [ ] 已发布内容到了收益假设的验证时间（24 小时 / 72 小时 / 7 天）还没有数据 → “有 N 篇该录数据了”（给录入 / 导入按钮）
- [ ] 有待确认的进化提案（workspace/proposals/ 中 pending）→ 每周最多汇总提醒一次
- [ ] 按 EVOLUTION.md 的降级规则在本机数据上计算：有打法连续低于对照或基线 → 生成“降级提议”（只提议，不改任何文件）

## 提醒
- [ ] 今天到期的提醒（subscriptions/reminders.json）
- [ ] 已通过但未发布超过 3 天的草稿 → “还有 N 篇待发布”（按 PROACTIVE_PREFERENCES.md 决定是否提醒）

## 绝不做
- 不调用任何生成模型，不访问任何平台，不自动发布，不删除任何东西，不修改任何系统文件与技能。
