# 决策路由表（最小有效模型）

> 读完 PRINCIPLES.md 后查本表：找到最像的一行，只加载这一行列出的模型段落（≤3 个）；“最小步骤”能解决就不进完整流程；只有当用户要做决定、要可复用的方案，或最小步骤给不出可检验结论时，才走“流程”列的完整流程。多行同时命中时取最贴近用户原话的一行，第二行的模型最多再借 1 个。

## 0 先排除

| 情况 | 动作 |
|---|---|
| 改错字、调字数、换一个同义词、回一句客套话 | 直接做，不加载底座 |
| 医疗、法律、金融、平台规则、数据口径等事实问题 | 先查权威来源与当天官方页；底座不能替代 |
| 没有数据却要“为什么爆/为什么掉” | 停在“需要哪些数据”，最多给 2 个待验证假设 |
| 要求刷量、控评、自动互动、伪装身份、绕风控、夸大功效 | 拒绝并给合法替代；理论不为其背书 |

## 2 覆盖与升级规则
- 本表覆盖全部 10 个流程：① 选题（1–4、25、26）② 标题（5、6、23）③ 人设（9）④ 脚本（12、13、23、24）⑤ 评论区（16、17）⑥ 复盘（18–20）⑦ 变现（21、22）⑧ 封面/首帧（7、8）⑨ 品牌/账号（10、11、22）⑩ 短剧/短视频叙事（14、15、24）。
- 升级到完整流程的条件：用户要做决定（做不做、选哪个）、要可复用的方案，或最小步骤给不出可检验的结论。
- 降级条件：最小步骤已给出结论＋一句反证，且用户没有要求展开 → 直接交付，不加载流程。
- 模型冲突时（例如 M19 开放 vs 事实类必须可读）：读 conflicts-and-limits.md 对应条，按其调和办法选一个。
