## 三、1.4 怎么用这些结构（只借结构）

| 公开结构 | 1.4 的对应物 | 刻意不同之处 |
|---|---|---|
| 独立董事 ≥ 1/3、专门委员会独立董事过半数（L2、L3） | 董事会：董事长（你）+ CEO（执行董事）+ 独立董事 2 名（可 1–3），独立董事占比 ≥ 1/3；战略 / 审计 / 提名与薪酬三委员会独立董事过半数，审计委员会主席由独立董事担任 | “独立性”在 AI 里落到**模型与服务商不同 + 只读原始记录不读 CEO 总结 + 不参与执行**；只有一个模型时标“独立性弱” |
| 审计委员会行使监事会职权（L1、L2 2025 修正、L3 现行版） | 审计委员会直接收《内审报告》，CEO 只收抄送 | 不设“监事会”角色 |
| 三线模型（I1） | 第一道：事业部发稿前自检；第二道：法务合规部 + 风控岗（风险登记册）；第三道：内审 Agent（独立模型），向董事长与审计委员会汇报 | 内审独立于 CEO；三道防线同时运行，不是先后关卡 |
| COSO 五要素（I2） | 内控矩阵：每要素若干控制点（目标、活动、执行者、证据、测试方法），由自检脚本自动测试，结果进年报“内控评价” | 只测本机可验证的控制，不出具“内控有效”的法律意见 |
| BLM（I3） | 年度战略沙盘：差距 → 市场洞察 → 战略意图 → 创新焦点 → 业务设计 → 关键任务 → 组织与人才 → 氛围与文化，输出战略地图、三情景，拆成 1.3 OKR | 市场洞察只用公开来源与用户录入数据 |
| 定期报告与业绩说明会（L4） | 季报 / 年报 11 章 + 业绩发布会 | 不对外披露；每个数字可追溯到本机记录，没有数据写“无数据” |
