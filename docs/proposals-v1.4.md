## P3 独立董事的独立性规则　风险：高　状态：待你确认
- 默认：独立董事绑定与 CEO 不同的模型，优先不同服务商；只读原始记录（账、日志、审计），不读 CEO 写的总结；不参与日常执行；每项议案必须写理由。
- 降级规则：同一服务商的另一个模型 → 标“独立性弱”；只有一个模型 → 换视角 + 较高温度跑两遍，标“独立性弱”；未接模型 → 本机模拟发言并标明。级别在董事会页与每份报告中如实显示。
- 你否决独立董事意见时记录在案，只提醒、不阻拦。
- 建议（可选）：接入第二家服务商，使独立董事达到“独立性强”（MiMo 实测中两位同模型独立董事结论高度一致，见 deviations V14-07）。
- 在 App 内确认：治理 → 董事会 → 董事会成员（显示每位独立董事的模型与独立性级别）。

## P4 治理成本上限　风险：高　状态：待你确认
- 默认：董事会、内审、经营分析、发布会、影子上岗、培训、报告、战略、年度大会的花费单独记入“治理成本”，上限 = 集团月预算的 **15%**；达到 80% 提示“接近上限”。
- 超上限后：发布会、影子上岗、培训、经营分析、战略、年度大会暂停到下月；内审、董事会、季报 / 年报继续，内审抽样从 10% 降到 5%。
- 单项上限：内审单次 ¥0.3、发布会单场 ¥0.5、影子上岗单次 ¥0.5。
- 未设集团月预算时无法计算占比，只显示本月治理成本。
- 在 App 内确认：治理 → 经营 → “集团月预算（¥，用于治理成本 15% 上限）”；15% 这一比例本版不提供界面修改，改动须经本建议确认后走章程与 DOA 修改议案。

## P5 商机评审门槛（经营收入与全球商机）　风险：高　状态：待你确认
- 默认：商机卡必须有**公开来源 + 核对日期**（官方页面、RSS、官方文档）才能被经营管理委员会评审通过；没有来源的卡（如比赛、知识付费模板）只能停在雷达里。
- 流程：经管会评审 → CEO 提案 → 你批准 → 工单；任一环节可否决。
- 预计收入一律标“估计”；没有你自己的数据前写“无数据”，不承诺收益。
- 工单里登录、接受条款、提交 / 投稿 / 发布、绑定收款、确认结算、报税都标“你本人”；Agent 不持有资金、不收款付款、不注册账号、不签约、不报税；越界步骤被引擎拒绝。
- 在 App 内确认：治理 → 经营收入 → 商机卡（评审 / 提案 / 批准按钮即确认点）。
