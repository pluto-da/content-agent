# ADR-025 三道防线与内审：三线同时运作；内审用独立模型、规则化抽查，报告直送董事长，CEO 只收抄送

- 状态：已采纳（1.4.0，2026-10-24）
- 相关：ADR-023；shared/src/listed/oversight.ts（runAudit / AUDIT_CHECKS / AUDIT_DEFAULTS / CONTROLS / runControlTests / 风险登记册）；design/refs-v1.4 I1（IIA 三线模型 2020）、I2（COSO 2013）

## 背景
1.3 的否决权和质量委员会都在“事前”；缺少事后独立复核。IIA 三线模型强调三条线同时存在、不是先后关卡；COSO 2013 给出内控五要素。

## 决定
1. 第一道（业务自控）：事业部发稿前按制度库清单自检。第二道（风控合规）：法务合规部 + 风控岗维护风险登记册，每月更新。第三道（内审）：审计委员会下的内审 Agent，使用与 CEO 不同的模型。
2. 内审每月抽查一次，默认抽样 10%、花费上限 ¥0.3、整改期限 14 天；六类检查：花费账与用量一致（只核本地记账）、DOA 有没有被越权或绕过、退回 / 否决是否引用条款、硬边界是否触碰、数据有没有出处、有没有编造数据。
3. 检查规则化、可复现；模型只用于写报告摘要（可选，受 ¥0.3 上限约束）。报告 = 发现 → 证据 → 等级 → 整改建议 → 责任部门 → 期限，编号“内审〔年〕NNN号”，收件人董事长与审计委员会，CEO 只在抄送。下期报告自动跟踪上期整改并关闭。
4. 内控矩阵按 COSO 五要素列 12 项控制，每项有负责部门、证据与自动测试（如 gov_cap：治理成本上限生效）。
5. 治理成本超上限时内审不暂停，抽样降到 5%（ADR-026 / gov.ts GOV_ESSENTIAL）。

## 取舍
- 不让模型判断“有没有越权”：越权、无出处、编造都按记录规则判定，模型写摘要也不改结论。
- 代价：规则只能发现记录里看得见的问题；没记账的事内审查不到。

## 后果
- 机制测试：内审报告直送董事长、CEO 只收抄送；整改下期跟踪关闭；内控自动测试（accept-v1.4 G4、G5、G6）。walkthrough 第 4 步：抽查发现一次越权和一处无出处数据并闭环。
