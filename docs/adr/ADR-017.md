# ADR-017 MCP 客户端：2026-07-28 无状态优先，兼容 2025-11-25；逐工具授权

- 状态：已采纳（1.2.0，2026-10-24；规范核对见 docs/refs-v1.2/README.md）
- 相关：ADR-016；shared/src/super/mcp.ts

## 决定
1. 只支持远程 Streamable HTTP。先 `server/discover`；支持 2026-07-28 就走无状态（每个请求 `_meta` 带版本，头 `MCP-Protocol-Version` / `Mcp-Method` / `Mcp-Name`，`input_required` → 用户回答 → 带 `inputResponses` 重试，≤3 轮）；不支持则回退 2025-11-25 的 initialize 握手与 `Mcp-Session-Id`。
2. 添加服务器 = L3；列出全部工具逐个勾选，默认 L2，最高 L2；写入外部系统的默认关闭且逐次确认；无法判定的逐次确认。
3. 社交互动类（点赞、评论、私信、关注、发帖、批量操作账号）按工具名 + 描述规则注册即拒，调用时二次检查（含参数）。
4. 凭据只存 `secretRef`，调用时现取，不进日志、备份、VFS。
