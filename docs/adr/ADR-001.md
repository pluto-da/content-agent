# ADR-001 能力角色是模型配置的主键

- 状态：已采纳（0.9.0，2026-10-23）

## 背景
0.8 只有“服务商 + 一个模型名”，生图、配音、转写、视频无处可配；用户要求“模型分家”。

## 决定
以 11 个能力角色（文本对话、深度推理、快速小模型、看图、生图、改图、配音、转写、视频、向量、重排）为主键，分 5 组；账号（一家服务商一把 Key）→ 模型名条目（各勾能力）→ 角色绑定（默认 / 备用 / 按任务）。注册表冻结在 shared/src/models/roles.ts。

## 后果
配置可以表达“百炼一个 Key 同时做文本、生图、配音”；新增角色只需注册 + 适配器 + 卡片。代价：v2→v3 迁移与 0.8 接口兼容层（getModels 由 v3 推导）。

## 何时重审
当出现第 12 类能力（音乐、3D）或角色之间需要组合调用时。
