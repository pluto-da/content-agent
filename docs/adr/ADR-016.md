# ADR-016 权限分级 L0–L3 + 禁止级；按 Agent 预算；审批收件箱；一键暂停

- 状态：已采纳（1.2.0，2026-10-24）
- 相关：ADR-014；shared/src/super/governance.ts

## 决定
1. 级别：L0 只读（自动）、L1 本机写（自动，审计，可回滚）、L2 花钱 / 外联（受预算，超阈值审批）、L3 核心（改核心文件、建子 Agent、授予权限、启用外部工具、启用 A2A、新平台技能、启用工作流定时——必须用户确认）、禁止（硬边界，注册表拒绝）。
2. 判定 = 调用者授权 ∩ 工具级别 ∩ 工具白名单；结果写审计（detail.agentId）。不改 1.1 的 `ToolLevel`，由 `permLevelOf` 推出 L3 / 禁止。
3. 预算顺序：全局月度预算（1.0）→ 子 Agent 月额度（默认 ¥3）→ 单次上限（默认 ¥1）。超额度暂停并进收件箱，不挪用。
4. 审批收件箱 6 类：花钱超阈值、L3 动作、核心文件修订、新建子 Agent、新平台技能、外部工具启用；批准 / 拒绝 / 修改后批准。
5. 一键暂停：RunRegistry 取消全部运行、排队、定时与外部工具连接（≤1 秒），之后拒绝新运行，恢复只能手动。
## 理由
“超级 Agent 管控所有”与“用户管控超级 Agent”同时成立的前提是：权力只能自上而下授予、逐级收窄，任何层级都不能放宽硬边界。
