# ADR-008 Agent 文件系统（VFS）+ 系统文件只能经用户确认修改

- 状态：已采纳（0.9.0，2026-10-23）

## 背景
Agent 设定、记忆、技能要可看、可改、可回滚，且 Agent 不能自己改自己的规则。

## 决定
VFS（路径为键、每次写入留版本、系统文件与技能永久保留版本）；Agent 只能提修订建议，用户看 diff 后采纳，可一键回滚；BOUNDARIES.md 由代码常量生成、只读；目录守护器保证入口文件与索引一致。

## 后果
“进化”可审计、可撤销。代价：版本数据占空间（非系统文件 90 天 / 20 版修剪）。

## 何时重审
出现多设备同步需求时（需要冲突裁决，已在 core/sync.ts 预留）。
