# ADR-018 A2A：beta、默认关闭；客户端受同等治理，服务端只在自己的服务器上、请求先进收件箱

- 状态：已采纳（1.2.0，2026-10-24；A2A v1.0）
- 相关：ADR-016；shared/src/super/a2a.ts、server/src/modules/a2a.ts

## 决定
1. 开关 `a2a.client`、`a2a.server`（beta）默认关闭。
2. 客户端：读 `/.well-known/agent-card.json`，校验 v1.0 必填字段（name、description、version、supportedInterfaces、capabilities、skills）与密钥；外部 Agent 作为“外部子 Agent”，调用 = L2，额度默认 ¥3/月，添加与启用 = L3。JSON-RPC 方法 `SendMessage`。
3. 服务端：只在“连接自己的服务器”模式下、开关打开且配置 ≥16 位口令时开放；Agent Card 只含勾选技能、声明 Bearer、不含 Key；`/a2a` 只接受 SendMessage，请求写入待批列表、回复 TASK_STATE_SUBMITTED，不自动执行。手机本机模式不开放端口。
