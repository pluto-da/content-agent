# ADR-024 董事会与独立性：独立董事绑定与 CEO 不同的模型，只读原始记录；董事长有最终决定权、否决留痕

- 状态：已采纳（1.4.0，2026-10-24）
- 相关：ADR-019（融合组织）、ADR-023（DOA 引擎）；shared/src/listed/board.ts（defaultBoard / pickIndependentModels / independenceOf / AGM_STEPS / BOARD_MATTERS）、gov.ts（checkGovResolution / governanceGrants）；design/refs-v1.4 L1–L3；design/proposals-v1.4.md P1–P3

## 背景
1.3 的集团里，CEO（超级 Agent）既做事又汇报自己做得怎样，缺少“有人专门挑毛病”的一层。真实上市公司用独立董事和专门委员会解决这个问题（《公司法》2023 修订、《上市公司独立董事管理办法》2025 修正、《上市公司治理准则》2025）。AI 版的“独立”不能靠身份，只能靠**不同的模型 + 不同的信息来源**。

## 决定
1. 组成：董事长（你）+ 执行董事（CEO）+ 独立董事 1–3 名（默认 2）+ 董事会秘书（不是董事，负责议程、结论先行的会前材料与纪要）。股东会 = 你一个人的年度大会，四步按顺序：审议年报 → 使命 / 愿景 / 目标 → 预算总额 → 章程修改（章程修改过硬边界检查）。
2. 独立性分级（pickIndependentModels）：不同服务商 → “独立性强”；同一服务商的另一个模型 → “独立性弱”；只有一个模型 → 换视角 + 较高温度跑两遍，“独立性弱”；未接模型 → 本机模拟发言并标明。界面与报告如实显示级别。
3. 独立董事只读原始记录（账、日志、审计），不读 CEO 写的总结；不参与日常执行。
4. 议事：例会每季度一次，可临时召开；每项议案独立董事写“同意 / 反对 / 弃权 + 理由”；董事长拍板，否决独立董事意见时记录在案（只提醒、不阻拦）。
5. 董事会事项：战略、年度预算、季度预算调整、组织大调整、章程与 DOA、高风险进化、接班交接、听取内审报告、提交年度大会。
6. 三个专门委员会（战略、审计、提名与薪酬）独立董事过半数，审计委员会主席由独立董事担任；1.3 的经管会、人资委保留，向董事会报告。
7. 一切决议过 `checkGovResolution`：触碰硬边界、要求提升权限、涉及真实证券 / 股权 / 融资 / 对外披露即拒并审计；`governanceGrants` 恒为空——治理只增加监督，不增加任何权限。

## 取舍
- 不把“独立董事”做成一句提示词：没有第二个模型时宁可标“弱”，不冒称独立。
- 董事长否决不被阻拦：用户是唯一股东，治理的作用是让决定有记录、有理由，而不是替用户做主。
- 代价：只接一家服务商时，两位独立董事结论趋同（MiMo 实测已见，deviations V14-07）。

## 后果
- 机制测试：独立董事模型 ≠ CEO 模型；单模型显示“独立性弱”；否决留痕；硬边界决议被拒（accept-v1.4 G2、G3、G21）。
- 独立性规则的默认值属于高风险改动，只写 proposals-v1.4 P3，已安装用户在 App 内确认。
