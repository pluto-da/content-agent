# ADR-004 Key 只在安全存储，永不进备份 / 日志 / VFS

- 状态：已采纳（0.9.0，2026-10-23）

## 背景
0.8 的 Key 明文在 kv 里，且备份可选“同时导出 API Key”。

## 决定
Key 进 WebCrypto AES-GCM 加密存储（加密密钥为不可导出 CryptoKey）；配置只存 secretRef 与末 4 位；saveModelsV3、VFS 写入、导出前后都做密钥扫描，命中即拒绝；删除备份页“同时导出 API Key”。

## 后果
换机需重新填 Key（界面明确提示）。代价：安卓上尚未绑定硬件 Keystore（见 deviations-v9 D-KEYSTORE，ROADMAP 0.10）。

## 何时重审
0.10 原生 Keystore 插件完成真机验证后，改为硬件绑定。
