# ADR-003 数据只增不改 + 前滚 / 回滚迁移 + zip 备份

- 状态：已采纳（0.9.0，2026-10-23）

## 背景
0.9 需要新集合（媒体、用量、VFS、运行、审计、收益…）与新配置结构，用户数据只在手机上。

## 决定
IndexedDB 升到 v3 只新增集合；配置与备份用 Migrator（up / down、幂等、未来版本只读）；备份改为 zip（manifest + sha256 + vfs/ data/ kv/），恢复前自动快照可撤销，旧 JSON 备份前滚。

## 后果
升级不丢数据、可回滚到 0.8 兼容备份；备份可校验。代价：IndexedDB 不能降版本，回 0.8 只能走导出。

## 何时重审
引入服务端同步（sync.server 开关打开）时。
