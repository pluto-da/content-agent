# ADR-027 接班人计划：影子上岗并跑 + 独立董事盲评 + 数据复核，才交接；交接后保留回滚

- 状态：已采纳（1.4.0，2026-10-24）
- 相关：ADR-014（进化分级）、ADR-022（赛马与灰度）；shared/src/listed/talent.ts（SHADOW_DEFAULTS / COMP_RULES / COMP_RULES_TEXT / 提名 / 季度考核）

## 背景
换模型或换提示词是 Agent 组织里最大的“人事变动”：换得好省钱提质，换得差悄悄降质。1.0 的自主进化与 1.3 的灰度解决了“小改动”，缺少对“换人”的正式流程。

## 决定
1. 影子上岗：候选（新模型 / 新提示词）与在任者并跑 N 个任务（默认 10，费用上限 ¥0.5），输出不对外。
2. 盲评：独立董事只见 A / B 代号评质量；揭盲后再看花费数据。
3. 交接门槛：候选质量不低于在任者，且花费 ≤ 在任者 × 1.2，才可申请交接；交接是董事会事项。
4. 交接即生成 1.3 灰度记录；交接后保留回滚，一键回到在任者。
5. 提名：新设 Agent 或负责人时提名与薪酬委员会出候选方案（模型、技能、权限、预算），经董事会或董事长批准；权限不得高于 DOA 上限。
6. 薪酬 = 资源激励（预算配额、模型档位、并发优先级），规则公开：考核分 = KPI（只用可验证数据）× 70% + 360 评议 × 30%；有收入数据时贡献利润正 +5、负 −5；单个 Agent 配额上限 ¥20 / 月；任何档位变化不改变权限。

## 取舍
- 不按“新模型更强”自动替换：必须有并跑数据与盲评。
- 代价：每次接班约 ¥0.5 与 10 个任务的时间。

## 后果
- 机制测试：影子上岗可以回滚（accept-v1.4 G15、G16）；walkthrough 第 8 步：影子上岗 10 个任务 → 盲评 → 交接 → 回滚。
- 影子上岗属治理成本，超 15% 上限时暂停到下月。
