# ADR-010 评测以回放为主、真实模型为辅

- 状态：已采纳（0.9.0，2026-10-23）

## 背景
无真实 Key 的环境也要能证明 Agent 行为；真实模型输出不稳定。

## 决定
黄金任务 G01–G28 与行为评测 BQ-01–BQ-32 用录制回放驱动真实运行时 / 工具 / 审批代码，CI 每次跑；真实调用（CA_REAL_MIMO=1）单独执行，结果另存 trace（不含 Key）。

## 后果
CI 可复现、零花费。代价：话术质量只能在真 Key 下复测（deviations-v9 D-EVAL）。

## 何时重审
用户提供长期测试 Key 并同意每次 CI 花费时。
