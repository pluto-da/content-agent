# ADR-012 AIGC 隐式标识：纯 TS 改写元数据，保留服务商已有标识

- 状态：已采纳（0.10.0，2026-10-23）

## 背景
0.9.0 只给 PNG 写了隐式标识（deviations-v9 D-AIGC）。生图可能返回 JPEG，配音返回 MP3 / WAV，视频返回 MP4。

## 决定
`web/src/v10/aigcMedia.ts`，不引第三方库、不重编码：
- JPEG：EXIF UserComment（UNICODE）+ XMP（dc:description 与自定义命名空间 `http://ns.content-agent.local/aigc/1.0/`，前缀 AIGC：Label、LabelText、ContentProducer、ProduceID、Model、Time、ContentPropagator、PropagateID、整段 JSON）。已有 EXIF 时只在 TIFF 末尾追加新 Exif IFD 并改指针，原数据一字节不动；新建 Exif IFD 时补齐 EXIF 必需字段（exiftool -validate 告警不多于原图）。
- MP3：ID3v2.4 TXXX:AIGC（已有 v2.3 时按 v2.3 帧格式写）；WAV：LIST/INFO ICMT；可选开头 0.5 秒提示音（开关 media.audioCue，默认关，只对 16 位 PCM WAV）。
- MP4：只改 moov：udta/©cmt（QuickTime 文本）+ udta/meta/ilst（©cmt 与 `----` 自由格式 AIGC）；moov 在 mdat 前时修正 stco / co64。
- 服务商已有标识（UserComment、dc:description、TXXX:AIGC、ICMT、©cmt）一律保留：我们的信息作为“传播者”另写（AIGC_Propagator / 追加在原文之后），不覆盖。
- 字段结构参照 GB 45438-2025 隐式标识（Label / ContentProducer / ProduceID / ContentPropagator / PropagateID）；命名空间 URI 是本应用自定义的，不代表标准指定的 URI。
- 写不进去时 implicit=false + 白话原因，卡片与发布检查提醒在平台勾选 AI 生成声明。

## 后果
CI 有纯 TS 读回测试；exiftool / ffprobe 外部校验在工具可用时运行（CI verify 作业安装发行版包）。

## 何时重审
监管发布官方 XMP 命名空间或平台要求特定字段时。
