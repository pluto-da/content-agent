# ADR-028 集团大学与董事长学堂：案例自动沉淀并被引用、新 Agent 培训测验后上岗；学堂只鼓励不打卡

- 状态：已采纳（1.4.0，2026-10-24）
- 相关：shared/src/listed/university.ts（fromRetro / fromVeto / fromReturn / fromHit / fromIncident / injectCases / makeQuiz / gradeQuiz / canGoOnDuty / pickBestPractices / knowledgeHealth）、academy.ts（23 张卡片、每周一课、徽章、术语表）

## 背景
1.3 的复盘结论散落在纪要里，新 Agent 上岗时不知道集团踩过的坑。用户本人第一次当“董事长”，治理术语多，需要一个不打扰、能随手看懂的入口。

## 决定
1. 案例库：复盘、退回、否决、爆款、事故自动生成案例卡（情境 – 做法 – 结果 – 教训 – 适用条件），按来源去重；相关任务按检索 Top-K 注入上下文并计引用次数。1.3 的复盘结论升级时自动转为案例卡。
2. 入职培训：新建或升级 Agent 时读取相关制度与案例 Top-K，做 5 题小测验（题目由案例与基础制度生成、规则判分），≥4 题通过才能上岗；花费计入培训（治理成本）。
3. 最佳实践：每季度按引用与结果评选，进入技能模板，经灰度后推广。
4. 知识健康度：案例数、引用率、过期率（>180 天未引用提示复核）。
5. 董事长学堂：每个治理页顶部一句大白话 +“1 分钟看懂”卡片（中英文，23 张）；每周一课结合本周集团真实发生的事，已读不重复，可关闭；成长徽章（入门 / 稳健 / 老练）只鼓励，没有打卡和连续天数；术语悬停从术语表跳到卡片。

## 取舍
- 测验用规则判分而不是模型判分：可复现、零花费。
- 学堂不做打卡与推送：减少屏幕时间，符合“有事再点进来”。

## 后果
- 机制测试：测验判分正确；案例被引用（accept-v1.4 G17、G18）；walkthrough 第 9、10 步。
