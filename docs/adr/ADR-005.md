# ADR-005 Agent 运行时：唯一合法状态机 + 单写者锁 + 幂等工具调用

- 状态：已采纳（0.9.0，2026-10-23）

## 背景
0.8 循环可能重复扣费、并发写同一会话、失败后无法续跑。

## 决定
shared AgentRuntime：表驱动状态机（表外转移一律拒绝并可见）、会话锁（心跳 + 30 秒过期接管）、工具调用幂等键、检查点续跑、审批阈值、SelfCheck；web 侧只做存储与界面接线（engine.ts），保留 0.8 事件接口。

## 后果
续跑不重复扣费、取消保留产出；行为可用回放评测钉住。代价：运行时复杂度上升，用 agent.runtime.v9 开关保留应急退路。

## 何时重审
真实模型下判官评测稳定、0.8 回退路径一个版本无人使用后（预计 0.11）移除旧循环。
