# ADR-005 Agent 运行时：唯一合法状态机 + 单写者锁 + 幂等工具调用

- 状态：已采纳（0.9.0，2026-10-23）

## 背景
0.8 循环可能重复扣费、并发写同一会话、失败后无法续跑。

## 决定
shared AgentRuntime：表驱动状态机（表外转移一律拒绝并可见）、会话锁（心跳 + 30 秒过期接管）、工具调用幂等键、检查点续跑、审批阈值、SelfCheck；web 侧只做存储与界面接线（engine.ts），保留 0.8 事件接口。

## 后果
续跑不重复扣费、取消保留产出；行为可用回放评测钉住。代价：运行时复杂度上升，用 agent.runtime.v9 开关保留应急退路。

## 何时重审
真实模型下判官评测稳定、0.8 回退路径一个版本无人使用后（预计 0.11）移除旧循环。

## 重审（0.11.0，2026-10-23）
- **结论**：重审到期，旧循环移除。`agent.runtime.v9` 特性开关删除（shared/src/core/flags.ts），`web/src/agent/loop.ts` 删除；AgentPanel 只调 `runTurnV9`。事件与参数类型（AgentEvent / TurnOpts / TraceStep）与 `historyToMessages` 移到 `web/src/agent/events.ts`。
- **补到 v9 接线的 0.8 能力**（不补就会在回归里丢）：trace（B5：每次模型调用 / 工具调用一步）、toolMode 记忆（原生不支持时写回 ProviderConfig 为 json，首次原生成功写 native）、**中途切 JSON 指令模式时补系统提示里的指令规则**（0.9/0.10 只在开局按 toolMode 生成，中途切换后模型看不到格式——这是旧循环里有、v9 里漏掉的真实缺陷）、停止时保留已收到的部分并标 stopped、tasks 表检查点（task_resume 工具继续可用）、本轮 cfg 优先（会话内切模型立即生效）、消息标注实际返回的模型名。
- **0.8 回归测试**：web/src/agent.test.tsx、v081.test.tsx、real-mimo.test.tsx 改为调用 `runTurnV9`。按“每轮只决定下一步”编排的回放脚本对应 v9 的逐步模式（`agent.planner` 关）；4 处断言改为 v9 的等价观测（见 design/deviations-v11.md V11-3）：工具结果看 toolcalls 表而非 role=tool 消息；参数不合格的白话文案；重复调用在执行前拦下（工具 3 次而非 4 次，运行以“连续调用两次，已停下”结束）；停止后另起一条“已停止”说明。
- **应急退路**：不再有运行时开关；回退靠发版（上一个 APK 0.10.0 保留在 out/）。
- **下次重审**：1.0 引入费用护栏（policy.ts）时复核审批阈值与预算接口。
