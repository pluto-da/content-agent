# ADR-022 赛马与灰度：有预算上限的并行探索 + 盲评 + 董事长选定；新技能先灰度、指标下降自动回滚

- 状态：已采纳（1.3.0，2026-10-24）
- 相关：ADR-019、ADR-021；shared/src/group/race.ts、corp.ts；design/refs-v1.3/ T1、T2、T4

## 背景
腾讯赛马（微信为公开案例，T1）与灰度法则（T4）适合“方向不确定”的探索；2026 年也有报道指出赛马成本高、各家在收口（T2）。

## 决定
1. 赛马只对“高价值 + 方向不确定”的议题开；默认先复用共享能力中心。2–3 匹（上限 3）。
2. 专项预算：单次默认 ¥0.6、月度 ¥3（可调）；超出预算的马停下、不计入候选。
3. 盲评：评审只看到 A / B / C 代号与方案，不露 Agent、模型、部门；数据中心只在有历史数据时给预测，没有就不给。
4. 选定由董事长点选（CEO 需授权才能代选）；落选方案进素材库；胜出方案的后续效果只用录入数据统计（无数据 = 待录入）。
5. 灰度：新技能 / 新写法先在一个事业部或 20% 任务上试行一个观察周期；指标下降自动回滚到上一版、不扩大到全量。集团章程与 DOA 不走灰度（只走 L3）。

## 取舍
- 吸收“探索期并行、方向清晰后收口、要算账”这一可检验规律，不对任何公司下结论（refs-v1.3 第七节）。
- 盲评用同一模型的不同评审角色，仍可能有偏好；以代号隔离来源，并保留董事长终选。

## 后果
- MiMo 实测两匹马 ¥0.0008，盲评卡片不含 Agent 与模型名（evals/real/mimo-v1.3.json）。
- 机制测试：赛马预算上限、灰度回滚（accept-v1.3 F9、F10）。
