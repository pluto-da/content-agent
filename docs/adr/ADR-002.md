# ADR-002 服务商适配器 = 纯函数契约 + 注入传输

- 状态：已采纳（0.9.0，2026-10-23）

## 背景
18 家服务商接口差异大（同步 / 异步、JSON / multipart / 二进制、方言），本机与服务端都要调用。

## 决定
Adapter = { build, parse, classify, listModels?, poll? }，全为纯函数；Transport（fetch / CapacitorHttp）由调用方注入；runner 统一重试、备用、健康路由、缓存、记账。

## 后果
适配器可用假 HTTP 单测（每家至少 1 条录制样本）；新增一家 = 一个文件 + 注册一行。代价：流式与 multipart 在真机上的行为只能靠 CI 编译与真机验证。

## 何时重审
当某家服务只提供 WebSocket / SDK（如 CosyVoice 流式）且必须本机直连时。
