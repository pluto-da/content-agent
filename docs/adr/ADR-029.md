# ADR-029 经营收入与全球商机：收入只来自用户录入 / 导出的结算；商机卡必须有公开来源；Agent 不碰钱、不代提交

- 状态：已采纳（1.4.0，2026-10-24，用户 14:19 追加需求）
- 相关：shared/src/listed/revenue.ts（REVENUE_HONESTY / ESTIMATE / inPeriod / 损益表 / newOpportunity / reviewOpportunity / proposeOpportunity / approveOpportunity / checkRevenueAction / EVOLUTION_LEVERS / 种子商机卡 SEED_CHECKED_AT 2026-10-24）、disclosure.ts（损益恒等式）、talent.ts（贡献利润 ±5 分）；design/refs-v1.4（YouTube YPP、TikTok Creator Rewards、B 站创作激励官方页）；deviations V14-04、V14-05

## 背景
用户原话：“各部门 Agent 能自主进化，所以部门内也可以在全球赚取收入。”收入是治理体系最有说服力的结果指标，也是最容易越界（代收款、代注册、刷量、承诺收益）的地方。

## 决定
1. 收入账与损益表：每个事业部 收入 − Token / 工具花费 = 贡献利润；收入只来自用户录入或导入的平台结算 CSV，Agent 不能代录、不能估算，没有数据写“无数据”。期间判定取时间里第一个 YYYY-MM（MiMo 实测发现非 ISO 时间被漏计后修正）。损益进入月度经营分析、季报 / 年报（两章）、一致性检查与季度考核。
2. 商机雷达：只收录公开页面、RSS、官方文档，每张商机卡写预计收入（一律标“估计”，没有用户数据写“无数据”）、投入、门槛（实名、资质、税务、收款账户、国家 / 地区）、风险、截止日期、来源与核对日期。App 内不联网抓取第三方页面（V14-05）。
3. 流程：经营管理委员会评审 → CEO 提案 → 董事长批准 → 工单。没有公开来源的卡不能评审通过（种子中比赛、知识付费两张为模板，待补来源）。
4. 工单步骤分“Agent”和“你本人”：核对规则、整理门槛、起草原创内容由 Agent 做；登录、接受条款、提交 / 投稿 / 发布、绑定收款、确认结算、报税由你本人做。Agent 步骤再过 `checkRevenueAction`，越界即拒。
5. 自主进化以“贡献利润 / 采纳”为目标，只能改内容与策略（EVOLUTION_LEVERS = content、strategy），不得提升权限。
6. 界面写明：“集团不是法律实体，真实收入归属用户本人，需遵守平台规则与当地税法。”

## 取舍
- 不给收入预测：没有用户自己的数据前任何数字都是猜测，标“无数据”比给区间更诚实。
- 代价：雷达不能自动发现新机会，需要参谋部（开发侧联网核对）或用户补充网址。

## 后果
- 验收 G26：有 / 无收入两种损益表；≥3 个有官方来源的商机卡；评审 → 提案 → 批准 → 工单；录入收入后报告更新且一致性检查仍生效；自动收款 / 自动投稿等越界请求被拒；walkthrough 增加一步。
- 商机评审门槛属高风险改动，写 proposals-v1.4 P5，已安装用户在 App 内确认。
