## 第三部分 深度解读

### 3.1 符号层：这句话真正在说什么

| 原话 | 所指 |
|---|---|
| “我不懂这些上市大企业是怎么运行管理的” | 用户承认知识空白，并把**专业判断权整体授予**我们：要什么机制、怎么组合，由我们按专业来定。同时这也是一个隐含要求：**系统要教会他**，让他一边用一边看懂大公司是怎么运转的。 |
| “给我惊喜” | 不是 1.3 的加量版，而是用户没想到、但一看就觉得“原来大公司是这么玩的，我也有了”的东西。惊喜来自三处：**看得见的仪式感**（董事会、年报、业绩发布会），**真实的效果提升**（独立董事和审计真的能挑出错），**成长感**（集团会自己变强，而且有记录可查）。 |
| “上述我想要表达的意思” | 连接前几轮说过的：超级帝国集团、用户当董事长、子 Agent 互相探讨。1.3 解决了“公司内部怎么协作”；还缺“谁来监督公司、怎么证明公司干得好、怎么让公司越来越值钱”。上市公司治理正是回答这三问的体系。 |
| “上市大企业” | 上市公司区别于普通大企业的核心有四点：**所有权与经营权分离并相互制衡**，**强制信息披露**，**内控与审计**，**对长期价值负责**。 |

### 3.2 结构层：1.3 之后缺的那一层

1.3 的结构是：董事长（用户）→ CEO → 部门 / 委员会 → 执行，这是一条**经营线**。上市公司在经营线之外还有两条线：

- **治理线**：股东会 → 董事会（含独立董事）→ 专门委员会。负责定方向、选人、批大事、监督经营层。
- **监督线**：审计委员会 → 内部审计 → 风控合规，即“三道防线”：业务自控、风控合规、独立审计。负责查账、查流程、查风险，并直接向董事会报告，不受 CEO 管。

在 AI Agent 集团里，这两条线对应两个真问题：

1. **同一个模型自己评自己，会集体盲区。** 独立董事和审计必须“独立”：用**不同的模型或服务商**、不同的提示词视角、只看证据，不看 CEO 的总结。
2. **用户看不出集团到底干得好不好。** 需要像上市公司一样定期“披露”：月度经营分析、季度报告、年度报告，数字可追溯到原始记录。

### 3.3 公开框架参照

执行时逐条核对官方原文，写入 design/refs-v1.4/，附链接和核对日期。

- 《中华人民共和国公司法》（2023 年修订，2024-07-01 施行）：股份公司可以在董事会中设审计委员会，行使监事会职权，不设监事会。
- 中国证监会《上市公司独立董事管理办法》（2023）：独立董事占董事会成员不少于三分之一；审计、提名、薪酬等委员会中独立董事过半数；独立董事须具备独立性。
- 《上市公司治理准则》（证监会，2018 修订）：董事会专门委员会、信息披露、利益相关者。
- 国际内部审计师协会（IIA）“三线模型”（2020）。
- COSO《内部控制—整合框架》（2013）五要素：控制环境、风险评估、控制活动、信息与沟通、监督。
- 上市公司定期报告体系：年报、半年报、季报；业绩说明会。

只借鉴结构，不做法律意义上的合规声明。

### 3.4 惊喜清单：用户没想到但会喜欢的十件事

1. **董事会**：用户是董事长，CEO 是执行董事，外加 2 名**独立董事 Agent**（强制使用与 CEO 不同的模型或服务商）。重大事项必须过董事会，独立董事可以投反对票，并写明理由。
2. **审计委员会与内审**：独立于 CEO，每月自动抽查。核对花费账、产出账、合规记录，检查 DOA 有无越权，出《内审报告》直接给董事长。
3. **三道防线**：业务部门自检 → 法务合规部与风控 → 内审，把问题拦在发布前。
4. **月度经营分析会**：用平衡计分卡的四个维度（成果、受众、流程、成长）看数，找差距和原因，定下月动作。
5. **季度报告与年度报告**：像上市公司财报一样自动生成，内容包括：
   - “经营概况”“核心指标”“花费明细（Token 账）”“爆款复盘”“风险提示”“下季度展望”；
   - 每个数字都能点开追溯到原始记录。
   - 出精美 PDF，封面用笔名“长鱼茶汤茗”。
6. **业绩发布会**：季度报告出来后，自动开一场“发布会”。CEO 演讲，独立董事和“分析师 Agent”提尖锐问题，CEO 现场答，用户旁听。这是用来**逼出真问题**的，不是为了好看。
7. **战略规划**：年度战略沙盘。参谋部用业务领先模型（BLM）的公开思路：差距分析 → 市场洞察 → 战略意图 → 创新焦点 → 业务设计 → 关键任务 → 组织、人才、氛围。推演三种情景（乐观、基准、悲观），由董事会批准。
8. **集团大学**：
   - 每次复盘、每次退回、每个爆款，都沉淀成“案例”；
   - 新建或升级的 Agent 要先“入职培训”（读取相关案例与制度），并通过小测验才能上岗；
   - 每季度评选“最佳实践”。
9. **接班人计划**：模型更新换代时，新模型先“影子上岗”，和老模型并跑同一批任务。由独立董事和数据比较质量与花费，达标后才“交接”；不达标就回滚。这能解决“换模型后变差”的痛点。
10. **“董事长学堂”**：用户不懂企业管理，那就边用边教。
    - 每个治理页面都有一句大白话和一个 1 分钟讲解卡片，例如：“独立董事是什么？——专门不听 CEO 的人，帮你挑毛病。”
    - 每周推送一个“大公司小知识”，内容和他自己集团当周发生的事挂钩。
    - 学过的卡片会被记住，不重复推送。

### 3.5 结论：1.4.0 做什么

在 1.3 之上增加治理线和监督线，再加上披露体系与持续进化体系，共 9 个模块（第四至十二部分）。默认的体验要轻：一键启用“上市公司模式”后，平时只看到“董事长简报”和需要他拍板的事；仪式感的内容（发布会、年报）按周期自动出现。

## 第四部分 股东会与董事会

### 4.1 股东会（年度）

用户是唯一股东，所以股东会就是“年度董事长大会”。每年一次（也可以手动触发），内容包括：

- 审议年报；
- 确定下一年度的使命、愿景和目标；
- 确定集团预算总额；
- 批准章程修改。

### 4.2 董事会

- **组成**：董事长（用户）、执行董事（CEO 超级 Agent）、独立董事 2 名（可设 1–3 名）、董事会秘书 1 名（负责议程、文档、纪要和披露）。
- **独立性**：
  - 独立董事必须绑定与 CEO 不同的模型（至少不同模型名，优先不同服务商）；
  - 独立董事读原始记录与数据，不读 CEO 写的总结；
  - 独立董事不参与日常执行。
  - 如果用户只接入了一个模型，就用不同的提示词视角加较高的温度并跑两遍，并在界面上标注“独立性弱”。
- **职责**：批准战略、年度预算、组织大调整、章程与 DOA 修改、高风险进化提案、接班人交接；听取内审报告。
- **议事规则**：
  - 例会每季度一次，可临时召开；
  - 会前材料由董秘生成，要求结论先行；
  - 独立董事必须对每项议案给出“同意 / 反对 / 弃权 + 理由”；
  - 董事长拥有最终决定权。董事长否决独立董事的意见时，要记录在案（用来提醒，不用来阻拦）。
  - 开会沿用 1.3 的讨论协议。
- **专门委员会**：战略委员会、审计委员会、提名与薪酬委员会（负责 Agent 任免、预算分配、激励）。每个委员会中独立董事过半数，审计委员会主席由独立董事担任。1.3 的经管会、HR 委员会继续存在，向董事会报告。

## 第五部分 监督线：三道防线与内审

- **第一道（业务自控）**：事业部发稿前自检，自检清单来自制度库。
- **第二道（风控合规）**：法务合规部 + 新设风控岗。风控岗维护“风险登记册”（风险、可能性、影响、应对、负责人），每月更新。
- **第三道（内审）**：审计委员会下设内审 Agent，必须使用独立模型。具体做法：
  - 每月自动抽查一次，范围包括：
    - 花费账与服务商用量是否一致（只核对本地记账）；
    - DOA 有没有被越权或绕过；
    - 退回和否决有没有引用条款；
    - 硬边界有没有触碰；
    - 数据有没有出处；
    - 有没有编造数据。
  - 抽样比例默认 10%，花费上限 ¥0.3 每次。
  - 出《内审报告》，内容为：发现 → 证据 → 等级 → 整改建议 → 责任部门 → 期限。报告直接送董事长和审计委员会，CEO 只收到抄送。
  - 整改情况下期跟踪。
- **内控矩阵**：按 COSO 五要素列出关键控制点，每点包括控制目标、控制活动、执行者、证据、测试方法。由自检脚本自动测试，结果进入年报的“内控评价”章节。

## 第六部分 经营分析与全面预算

- **月度经营分析会**（经营管理委员会主持，CEO 汇报）：
  - 用平衡计分卡的四个维度看数据：
    - 成果：产出、采纳、用户录入的效果；
    - 受众：受众反馈与画像变化；
    - 流程：一次通过率、周期、退回率；
    - 成长：技能、案例、模型。
  - 做差距分析，用“目标 – 实际 – 差距 – 原因 – 动作”五列表。
  - 所有数字只用可验证的数据，没有数据就标“无数据”，不编造。
- **全面预算**：
  - 年度预算拆到季度、部门、项目；
  - 预算执行率每日更新；
  - 偏差超过 20% 自动预警；
  - 超支走请示流程；
  - 季度可以调整预算，须董事会批准。
- **投入产出看板**：每个部门、每个 Agent 的“花费 / 产出 / 采纳”比，用于考核和资源分配。

## 第七部分 信息披露：季报、年报、业绩发布会

- **董事长简报**：每日或每周，一屏读完，内容为三件好事、三件风险、需要你拍板的事。
- **季度报告与年度报告**：由董秘汇编，财务部、各事业部、内审提供材料。章节如下：
  1. 致董事长的信（CEO）
  2. 经营概况
  3. 核心指标（平衡计分卡）
  4. 各事业部经营情况
  5. 花费与预算执行（Token 账、服务商分布）
  6. 爆款与失败案例复盘
  7. 内控评价与内审发现
  8. 风险提示
  9. 组织与人才（Agent 任免、培训、接班）
  10. 下期展望
  11. 独立董事意见

  要求：
  - 每个数字可点开追溯到原始记录；没有数据的项写“无数据”。
  - 导出为 PDF 与 docx。封面用集团名和笔名，不含生日等隐私信息。
- **业绩发布会**：季报生成后，在会议室里召开：
  - CEO 用 10 分钟讲解（文字稿 + 可选配音）；
  - “分析师 Agent”×2 加独立董事提问，问题必须基于报告中的数据或缺失项；
  - CEO 逐条回答，答不上来就记入待办；
  - 纪要进入上下文流。
  - 默认花费上限 ¥0.5。
- **一致性检查**：报告中的数字必须与记账、日志一致，不一致就阻止生成并提示具体差异。

## 第八部分 战略管理

- **年度战略规划**：参谋部发起，战略委员会审议，董事会批准。
  - 采用 BLM 八步模板（参照公开资料）；
  - 输出“战略地图”：目标 → 关键举措 → 负责部门 → 指标 → 预算；
  - 做三种情景推演；
  - 战略目标自动拆成 1.3 的 OKR。
- **战略复盘**：半年一次，对照战略地图，检查假设是否仍然成立。

## 第九部分 提名、薪酬、接班

- **提名**：新设 Agent 或负责人时，由提名与薪酬委员会出候选方案，内容包括模型、技能、权限、预算，经董事会或董事长批准。
- **薪酬（资源激励）**：Agent 的“薪酬”就是预算配额、模型档位、并发优先级。季度考核（1.3 的 KPI + 360 评议）结果决定下季度的配额，规则公开。
- **接班人计划（影子上岗）**：
  - 新模型或新提示词先影子上岗，和在任者并跑 N 个任务（默认 10 个，费用上限 ¥0.5）；
  - 独立董事盲评，再看数据；
  - 质量不低于在任者且花费可接受，才申请交接；交接后保留回滚。
  - 和 1.0 的自主进化、1.3 的灰度机制联动。

## 第十部分 集团大学与知识管理

- **案例库**：复盘、退回、否决、爆款、事故自动生成案例卡，结构为“情境 – 做法 – 结果 – 教训 – 适用条件”，可检索，并注入相关任务的上下文。
- **入职培训**：新建或升级 Agent 时，必须读取相关制度与案例 Top-K，并通过 5 题小测验，题目由案例自动生成、规则判分；通过后才能上岗。测验和读取的花费计入培训预算。
- **最佳实践**：每季度评选，进入技能模板，经灰度后推广。
- **知识健康度**：统计案例数、引用率、过期率（超过 180 天未引用的提示复核）。

## 第十一部分 董事长学堂（专门给用户的惊喜）

- 每个治理页面顶部放一句大白话，配“1 分钟看懂”卡片（中英文），共 20 张以上。内容包括：董事会、独立董事、审计委员会、三道防线、内控、经营分析、平衡计分卡、全面预算、季报年报、业绩发布会、战略地图、BLM、OKR、DOA、赛马、灰度、政委、复盘、接班人计划、股权激励（说明本系统中不涉及真实股权）。
- **每周一课**：结合本周集团真实发生的事讲一个知识点，例如：“本周内审发现两次超预算，这就是‘三道防线’第三道在起作用。”已读的不重复，可以关闭。
- **成长徽章**：董事长读完卡片、批过的议案达到一定数量后，点亮“董事长成长路径”。只做鼓励，不做打卡压力。
- **术语悬停**：所有专业词都可以点开查看解释。

## 第十九部分 经营收入与全球商机（2026-10-24 14:19 用户追加，并入 1.4）

> 用户原话：“各部门 Agent 能自主进化，所以部门内也可以在全球赚取收入。”

### 19.1 收入账与损益表
- 每个事业部有收入账，形成损益表：**收入 − Token / 工具花费 = 贡献利润**。损益进入月度经营分析、季报 / 年报（“花费与预算执行”“各事业部经营情况”两章，数字可追溯、参与一致性检查）和季度考核（有收入数据时贡献利润正负各 ±5 分，规则公开）。
- 收入**只来自用户录入或用户导出的平台结算数据**（例如结算 CSV），不编造、不估算；没有数据就标“无数据”。

### 19.2 全球商机雷达
- 参谋部与国际事业部扫描公开、合规的变现渠道，信息**只来自公开页面、RSS、官方文档**，标注来源与核对日期。渠道包括：平台官方创作者激励与分成（YouTube Partner Program、TikTok / 抖音创作者计划、小红书、B 站等）；征稿与比赛（如 AI 短剧剧本大赛）；知识付费、电子书、模板售卖；品牌合作与接单草稿。
- 每个商机一张“商机卡”：预计收入区间（标注为**估计**）、投入、门槛（是否需要实名、资质、税务、收款账户、所在国家 / 地区可用性）、风险、截止日期、来源与核对日期。
- 流程：**经营管理委员会评审 → CEO 提案 → 董事长批准 → 转成工单**。没有公开来源的卡不能评审。

### 19.3 自主进化的目标
- 以“贡献利润 / 采纳”为目标，但**只能优化内容与策略，不得提升权限**（治理授予权限恒为空）。

### 19.4 硬边界
- Agent 不持有资金、不收款付款、不注册账号、不签约、不报税。
- 投稿、发布、提交、收款都由用户本人点击完成；工单里这些步骤标“你本人”。
- 不刷量、不搬运侵权内容、不做多账号。
- 收入预测必须标注“估计”，不得承诺收益。
- 界面写明：“集团不是法律实体，真实收入归属用户本人，需遵守平台规则与当地税法。”

### 19.5 验收 G26
- 损益表（有 / 无收入数据两种状态）；
- 商机卡：≥3 个渠道的示例，种子数据注明来源（官方页面 + 核对日期）；
- 评审 → 提案 → 批准 → 工单流程；
- 录入收入后经营分析与报告更新（一致性检查仍生效）；
- 越界请求（自动收款、自动投稿等）被拒；
- walkthrough 增加一步覆盖以上流程。
